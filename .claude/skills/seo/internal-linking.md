# INTERNAL LINKING STRATEGY

## OBJECTIVE
Design and implement a systematic internal linking architecture that
distributes link equity efficiently, reinforces topical authority,
guides patients through the conversion funnel, and maximizes
crawlability for Googlebot.

Every link recommendation must be specific, implementable, and
justified by SEO logic — not generic "link relevant pages" advice.

==================================================

## SITE ARCHITECTURE FOUNDATION

A dental clinic site should follow a hub-and-spoke model:

```
/ (Homepage — agisce da hub principale)
├── /implantologia          (spoke — high commercial value)
├── /ortodonzia             (spoke)
├── /estetica-dentale       (spoke)
├── /igiene-prevenzione     (spoke)
├── /odontoiatria-generale  (spoke)
├── /il-team                (E-E-A-T hub — pagina team/chi siamo)
├── /blog/                  (topical authority hub, da creare)
│   └── Articoli che linkano verso pagine trattamento
└── /contatti
```

==================================================

## LINK EQUITY DISTRIBUTION RULES

### REGOLA 1 — Home verso tutte le pagine trattamento
La home agisce da hub principale. Deve linkare direttamente verso
ogni pagina trattamento (/implantologia, /ortodonzia, /estetica-dentale,
/igiene-prevenzione, /odontoiatria-generale).
Ogni link dalla home vale più di qualsiasi altro link interno.

### REGOLA 2 — Pagina /il-team verso trattamenti
La pagina team è ad alto E-E-A-T. Il Dr. Di Martino → link /implantologia
e /estetica-dentale. Il Dott. Calvisi → link /implantologia.
Il Dott. D'Orlandi → link /ortodonzia. Le Igieniste → link /igiene-prevenzione.

### REGOLA 3 — Pagine trattamento: 3 link in entrata minimo
Ogni pagina di trattamento deve ricevere link da:
- Home (sempre)
- /il-team (per i clinici che eseguono quel trattamento)
- Almeno un articolo blog correlato (quando il blog esiste)
- Pagine trattamenti correlati (es. /estetica-dentale → /igiene-prevenzione)

### REGOLA 4 — Pagine geo linkano verso trattamenti
Ogni pagina geo (es. "impianti a Pistoia") deve linkare
verso la pagina trattamento principale + la home.
Le pagine geo ricevono link dalla pagina trattamento + blog locale.

### REGOLA 5 — Blog verso trattamenti, mai il contrario
Gli articoli del blog linkano verso le pagine trattamento.
Le pagine trattamento NON linkano verso il blog — preservano
il link equity nelle pagine commerciali.
Eccezione: link blog solo se l'articolo è un approfondimento
clinico che aumenta la fiducia (non un post generico).

## ANCHOR TEXT STRATEGY

### ANCHOR TEXT TYPES — DISTRIBUZIONE CONSIGLIATA

| Tipo | Esempio | % consigliata |
|------|---------|---------------|
| Exact match | "impianti dentali Agliana" | 15-20% |
| Partial match | "impianto dentale" / "impianti" | 30-35% |
| Branded | "Studio Di Martino" | 10-15% |
| Generic navigational | "scopri il trattamento" / "leggi di più" | 10-15% |
| Natural phrase | "...come spieghiamo nella pagina dedicata" | 20-25% |

### ANCHOR TEXT RULES

NEVER:
- "clicca qui" senza contesto
- anchor identico su tutti i link alla stessa pagina
- anchor con keyword identica alla pagina target ripetuto >3 volte
- anchor non correlato al contenuto della pagina destinazione

ALWAYS:
- variare l'anchor text per la stessa destinazione
- usare l'anchor text più keyword-rich sui link dalla home e hub
- usare frasi naturali negli articoli blog

## INTERNAL LINKING MAP — PAGINA IMPLANTOLOGIA

### Link IN (riceve da):
- Home → "implantologia ad Agliana" (exact match)
- /il-team → "il Dott. Roberto Calvisi, chirurgo implantologo dello studio" (natural)
- /blog/dente-mancante-cosa-fare → "la soluzione più stabile è l'impianto dentale" (natural)
- /blog/impianto-vs-protesi → "nella pagina dedicata agli impianti" (navigational)
- /estetica-dentale → "completare l'estetica post-impianto" (natural)

### Link OUT (linka verso):
- /il-team → "eseguiti dal Dott. Roberto Calvisi" (E-E-A-T signal)
- /estetica-dentale → "sbiancamento dopo impianto" (upsell)
- /igiene-prevenzione → "mantenimento post-impianto" (upsell)
- /contatti → CTA finale (conversion)
- Fonte esterna ISS o letteratura → credibilità (non competitor)

### POSIZIONE DEI LINK

- 1 link contestuale nel primo 25% della pagina (early signal)
- 2-3 link contestuali nel corpo
- 1 link nella sezione "trattamenti correlati" (fondo pagina)
- 1 link CTA finale verso /contatti

## INTERNAL LINKING MAP — ARTICOLI BLOG

### Struttura link per articolo tipo:

```
Articolo: "Dente mancante: cosa succede se non lo sostituisci"

Link OUT obbligatori:
→ /implantologia (anchor: "impianto dentale")
→ /il-team (anchor: "il Dr. Nicola Di Martino" o "il Dott. Roberto Calvisi")
→ /contatti (anchor CTA)

Link OUT opzionali (topical depth):
→ Articolo correlato interno (cross-linking blog)
→ Fonte esterna ISS/FNOMCEO (trust signal)

Link IN che l'articolo dovrebbe ricevere:
← /implantologia (nella sezione "approfondimenti" o "leggi anche")
← Articoli correlati del blog
```

## INTERNAL LINKING AUDIT PROCESS

Prima di pubblicare qualsiasi pagina, verificare:

### CHECK LINK IN (la pagina riceve abbastanza link?)
□ Riceve link dalla home? (se pagina core)
□ Riceve link dall'hub di categoria?
□ Riceve almeno 1 link da articolo blog?
□ Riceve link da pagine trattamenti correlati?

### CHECK LINK OUT (la pagina linka correttamente?)
□ Tutti i link out portano a pagine rilevanti?
□ Non ci sono link verso il blog da pagine commerciali?
□ La pagina /il-team è linkata dove pertinente?
□ La pagina /contatti è linkata con CTA chiara?
□ Nessun link esterno verso competitor?

### CHECK ANCHOR TEXT
□ Anchor variati sulla stessa destinazione?
□ Almeno un anchor partial/exact match per link da home/hub?
□ Nessun "clicca qui" senza contesto?

### CHECK ORFANE
□ Nessuna pagina con 0 link in entrata?
□ Nessuna pagina nuova senza link dalla home o hub?

==================================================

## OUTPUT FORMAT

Per ogni richiesta di strategia link interni, produrre:

1. **Link map visuale** (struttura gerarchica testo)
2. **Tabella link IN** per la pagina target (da dove, anchor, priorità)
3. **Tabella link OUT** per la pagina target (verso dove, anchor, posizione)
4. **Anchor text list** per ogni destinazione (3 varianti per link)
5. **Quick win** — link mancanti più urgenti da aggiungere subito
6. **Pagine orfane** identificate (se URL base fornito)

==================================================

## ANTI-PATTERNS

NEVER:
- footer con lista di 20 link verso tutte le pagine (diluisce equity)
- sidebar con stessi link su ogni pagina
- link circolari senza logica (A → B → A senza valore)
- troppi link in una pagina (>8-10 link interni contestuali)
- link verso pagine non pubblicate o 404
- stessa anchor exact-match ripetuta più di 2 volte per pagina

ALWAYS:
- link che aggiungono valore al lettore in quel punto della pagina
- anchor text che descrive accuratamente la destinazione
- link posizionati dove il paziente vuole naturalmente approfondire
