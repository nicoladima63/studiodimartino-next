# COMPETITOR DESTRUCTION

## OBJECTIVE
Systematically identify every exploitable weakness in competitor
pages and build a superior content strategy based on evidence,
not assumptions.

"Assume competitors are mediocre" is a mindset, not a method.
Always verify with data before strategizing.

==================================================

## PHASE 1 — SERP RECONNAISSANCE

Input required:
- target treatment
- target city
- search query to analyze

Steps:
1. Search "[trattamento] [città]" in incognito / SGE view
2. Record top 5 organic results (ignore ads)
3. Note: who ranks? Studio locale? Aggregatore? Blog?
4. Check map pack: chi compare? Con quante recensioni?
5. Check featured snippet: esiste? Chi lo possiede? È vulnerabile?
6. Check AI Overview: presente? Cita fonti locali o nazionali?

SERP COMPOSITION ANALYSIS:
- Se dominano aggregatori (Doctolib, MioDottore) →
  opportunità per contenuto locale più profondo
- Se dominano blog generici →
  opportunità per pagina locale con E-E-A-T superiore
- Se domina un competitor locale →
  analisi diretta obbligatoria (Phase 2)

==================================================

## PHASE 2 — COMPETITOR PAGE AUTOPSY

For each top 3 competitor page, map:

STRUCTURAL ANALYSIS:
□ Word count (approssimativo)
□ Numero di H2/H3
□ Presenza FAQ e numero di domande
□ Presenza schema markup (usa browser extension o
  schema.org validator)
□ Presenza author bio
□ Presenza data pubblicazione/revisione
□ Presenza mappa Google embed
□ Numero immagini e qualità alt text

SEMANTIC ANALYSIS:
□ Quali entità semantiche mancano?
□ Quali intent cluster non sono coperti?
□ La pagina risponde alla query fear-based?
□ La pagina risponde alla query cost-based?
□ Menziona controindicazioni?
□ Menziona tempi e procedimento step-by-step?

EEAT ANALYSIS:
□ Il clinico è identificato per nome?
□ Ci sono credenziali visibili?
□ Le statistiche hanno fonte?
□ C'è un disclaimer medico?
□ Il contenuto sembra scritto da un medico o da un copywriter?

LOCAL SEO ANALYSIS:
□ NAP presente e corretto?
□ Menzione quartieri / zone limitrofe?
□ Google Maps embed?
□ Recensioni locali citate?
□ Indicazioni per raggiungere lo studio?

CONVERSION ANALYSIS:
□ CTA chiari e posizionati correttamente?
□ Numero di telefono visibile above the fold?
□ WhatsApp presente?
□ Prezzi o range di prezzo indicati?
□ Proposta di valore differenziante?

## PHASE 3 — GAP MATRIX

Dopo l'analisi, costruire una matrice:

| Elemento              | Competitor A | Competitor B | Competitor C | Nostro target |
|-----------------------|-------------|-------------|-------------|---------------|
| Word count            | ~800        | ~1200       | ~600        | >2000         |
| FAQ count             | 3           | 0           | 5           | 10+           |
| Author bio            | No          | No          | Sì          | Sì            |
| Schema markup         | No          | Parziale    | No          | Completo      |
| Costi indicati        | No          | No          | No          | Sì            |
| Controindicazioni     | No          | No          | No          | Sì            |
| Mappa embed           | Sì          | No          | No          | Sì            |
| Intent fear-based     | No          | Parziale    | No          | Sì            |

Ogni "No" del competitor è un'opportunità diretta.

==================================================

## PHASE 4 — ATTACK STRATEGY

Basata sulla gap matrix, definire:

QUICK WINS (implementabili subito):
- elementi completamente assenti nei competitor
- schema markup mancante
- FAQ superficiali da sostituire con cluster profondi
- costi non indicati → trasparenza come differenziatore

SEMANTIC SUPERIORITY:
- intent cluster non coperti da nessun competitor
- entità semantiche mancanti
- domande reali dei pazienti non risposte

SNIPPET CAPTURE:
- identificare le query con featured snippet vulnerabile
- struttura risposta: definizione in 40-60 parole + lista/tabella
- target: snippet di tipo paragraph, list, e table

AI OVERVIEW OPTIMIZATION:
- citare fonti autorevoli esterne (ISS, letteratura)
- struttura domanda → risposta chiara
- contenuto che risponde direttamente alla query
- E-E-A-T alto aumenta probabilità di citazione

LOCAL DOMINANCE GAPS:
- competitor non menziona zone limitrofe → noi sì
- competitor senza mappa → noi con mappa + indicazioni
- competitor senza recensioni geo-tagged → noi con strategia GBP
