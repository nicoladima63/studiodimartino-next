# INTERNAL LINKING STRATEGY

## SITE ARCHITECTURE (studiodimartino.eu)

```
/ (Homepage — hub principale)
├── /implantologia
├── /ortodonzia
├── /estetica-dentale
├── /igiene-prevenzione
├── /odontoiatria-generale
├── /il-team (E-E-A-T hub)
└── /contatti
```

==================================================

## LINK EQUITY RULES

1. **Home → tutte le pagine trattamento** — link più potenti del sito
2. **/il-team → trattamenti per clinico** — Calvisi→/implantologia, D'Orlandi→/ortodonzia, Igieniste→/igiene-prevenzione
3. **Trattamento: min 3 link IN** — da home, /il-team, blog
4. **Pagine geo → trattamento + home**
5. **Blog → trattamenti** (mai il contrario — preserva link equity)

==================================================

## ANCHOR TEXT DISTRIBUTION

| Tipo | % |
|---|---|
| Exact match ("impianti dentali Agliana") | 15-20% |
| Partial match ("impianto dentale") | 30-35% |
| Branded ("Studio Di Martino") | 10-15% |
| Generic ("scopri il trattamento") | 10-15% |
| Natural phrase | 20-25% |

NEVER: "clicca qui", anchor identico ripetuto >3x

==================================================

## LINK MAP — /implantologia

IN: home, /il-team (Dott. Calvisi), blog, /estetica-dentale
OUT: /il-team, /estetica-dentale (sbiancamento post-impianto), /igiene-prevenzione (mantenimento), /contatti

□ Ogni pagina core riceve link dalla home?

□ Nessuna pagina con 0 link in entrata?
