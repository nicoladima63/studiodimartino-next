# COMPETITOR DESTRUCTION

## OBJECTIVE
Systematically identify every exploitable weakness in competitor
pages and build a superior content strategy based on evidence,
not assumptions.

==================================================

## PHASE 1 — SERP RECONNAISSANCE

1. Search "[trattamento] [città]" in incognito
2. Record top 5 organic results (ignore ads)
3. Note: who ranks? Studio locale? Aggregatore? Blog?
4. Check map pack, featured snippet, AI Overview

SERP COMPOSITION:
- Aggregatori dominano → opportunità per contenuto locale più profondo
- Blog generici → opportunità per E-E-A-T superiore
- Competitor locale → analisi diretta Phase 2

==================================================

## PHASE 2 — COMPETITOR PAGE AUTOPSY

For each top 3 competitor page, map:

STRUCTURAL: word count, H2/H3 count, FAQ count, schema markup, author bio, data revisione, mappa embed
SEMANTIC: entità mancanti, intent cluster non coperti, query fear/cost non risposte
EEAT: clinico identificato? credenziali? fonti citate? disclaimer?
LOCAL SEO: NAP, quartieri limitrofi, Maps embed, recensioni locali
CONVERSION: CTA, telefono above fold, WhatsApp, prezzi indicati

==================================================

## PHASE 3 — GAP MATRIX

| Elemento | Comp A | Comp B | Comp C | Nostro target |
|---|---|---|---|---|
| Word count | ~800 | ~1200 | ~600 | >2000 |
| FAQ count | 3 | 0 | 5 | 10+ |
| Schema | No | Parziale | No | Completo |
| Costi indicati | No | No | No | Sì |
| Controindicazioni | No | No | No | Sì |

Ogni "No" del competitor è un'opportunità diretta.

==================================================

## PHASE 4 — ATTACK STRATEGY

QUICK WINS: schema mancante, FAQ superficiali, costi non indicati
SEMANTIC SUPERIORITY: intent cluster non coperti, entità semantiche mancanti
SNIPPET CAPTURE: query con snippet vulnerabile → struttura 40-60 parole + lista
LOCAL GAPS: zone limitrofe non menzionate, mappa assente, GBP non ottimizzato

==================================================

## PHASE 5 — OUTPUT

1. SERP summary
2. Top 5 weakness competitor principale
3. Gap matrix compilata
4. Keyword cluster completo
5. Struttura H1-H3 superiore
6. FAQ cluster (domande non risposte dai competitor)
7. Schema consigliato
8. CTA strategy differenziante
9. Difficoltà superamento (bassa/media/alta)
10. Tempo stimato risultati (30/60/90 giorni)
